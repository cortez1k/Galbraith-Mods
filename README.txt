GALBRAITH SITE
==============

Требования:
- PHP 7.3+ с расширением sqlite3 (НЕ требуется pdo_sqlite!)
- Apache с mod_rewrite
- Права на запись в корень сайта и папку assets/uploads/

Установка:
1. Распакуйте содержимое архива в корень сайта (public_html или www).
2. Убедитесь, что папки assets/uploads/covers, screenshots, logos доступны для записи (chmod 755).
3. Файл database.sqlite создаётся автоматически при первом открытии сайта.
4. Вход в админку: /admin/login
   Логин: admin@galbraith-yt.ru
   Пароль: ChangeMe123!
   СРАЗУ смените пароль после первого входа!

Структура:
- index.php      — единая точка входа (роутер)
- includes/      — ядро (БД, функции, авторизация)
- pages/         — публичные страницы
- admin/         — панель управления
- templates/     — шапка и подвал
- assets/        — стили, скрипты, загрузки

Важно:
- Если ошибка 500 — проверьте, что sqlite3 включён в PHP (phpinfo).
- Если папки uploads/ недоступны — создайте вручную и выставьте права 755.
